Add experimental local tool plugins with one-command npm/GitHub install, managed replacement/removal and local link/list/unlink commands, static manifest validation, versioned devnet context, opaque argument forwarding and foreground process cleanup. Default to OS sandboxing on macOS/Linux; allow explicitly trusted packages to run natively on Windows/macOS/Linux without WSL or sandbox setup. Show the execution mode and retain environment filtering and host-provided read-RPC/HTTP capabilities in both modes, without claiming OS isolation for trusted execution. Include a generic context probe and protocol/security tests; install scripts are disabled by default, with explicit trusted build consent. Ship a fixed npm CLI for consistent preparation behavior on Node 20 and Windows. Key persistent storage by stable package name rather than command; preserve committed installations when post-commit cleanup fails. Bound RPC concurrency, connections and request lifetime, diagnose unavailable sandbox modes in listings and test the minimum supported Node 22 sandbox. Background services and automatic upgrades remain deferred.
